# 2026-06-30 実験記録

## プロジェクトを git 管理下に置き、患者データ・モデル・画像を除外して初回コミット

### 概要
- ユーザー要望「commit、画像は外して push してください」を受け、本プロジェクトを git 管理下に置いた。
- 状況確認の結果、(1) まだ git リポジトリではない(`git init` から必要)・リモート未設定・`gh` CLI 未インストール、(2) リポジトリ内に医用画像は1枚も無い(画像は外部フォルダ参照なので「画像は外して」は自然に充足)、(3) ただし `experiment.json` / `subsets.json` / `heldout_test.json` / 結果データには**患者ファイル名(患者ID付き)が埋め込まれており実質的に患者識別情報**、`outputs/models/*.pth` が **419MB** ある、という3点を整理しユーザーへ確認。
- 公開リモートへの患者由来データ push は取り消しにくいため、除外方針を固めてから実行。
- `.gitignore` を整備 → `git init` → **コミット前にステージ内容を検証** → 患者ファイル名・大容量モデル・ジャンクファイルが全て除外されていることを確認 → 初回コミット(`master`, 4716de3, 49ファイル)。
- `gh` CLI の自動インストールは UAC 昇格中断で失敗したが、ユーザーが空 private リポジトリ `https://github.com/ykitaguchi77/HITL_validation_test.git` を作成・提供 → `git remote add origin` / `git branch -M main` / `git push -u origin main` を **GCM のブラウザ1回サインインで実行し push 成功**。
- **push 後にリモート内容を機械検証**: リモート HEAD `4716de3` がローカルと一致、リモートのファイル数 **49**(ローカルと同数)、機微検索でヒットしたのは `scripts/make_training_subsets.py`(スクリプト本体=患者データ無し、正規表現がファイル名に部分一致しただけ)のみで、患者ファイル名そのものを含むファイルはリモートに皆無であることを確認。**患者由来でない成果物のみが Private リポジトリに安全にバックアップ**された。

### 変更ファイル
- `.gitignore` (新規) — 除外設計の本体
- リポジトリ初回コミット 4716de3 `Initial commit: blind HITL annotation experiment (code + docs)` (`master`, 49ファイル)

### `.gitignore` の除外/保持方針
| 区分 | 対象 | 扱い |
|------|------|------|
| 患者識別情報(ファイル名に患者ID) | `scripts/webapp/config/experiment.json`, `outputs/training_subsets/`, `outputs/results/` | **除外** |
| 大容量モデル(患者由来・419MB) | `outputs/models/*.pth` | **除外**(別途配布) |
| 入力データ | `data/` | 除外(元々外部参照) |
| 環境・ローカル | `.venv/`, `__pycache__/`, `.claude/settings.local.json`, `.claude/hooks/record.log` | 除外 |
| ジャンク(特殊文字を含む誤生成ファイル) | `*Eyelid_HITL_experiment_seg.txt` | 除外 |
| 安全な成果物 | `outputs/models/heldout_dice.csv`, 学習ログ(`*.log`), 研究ノート, コード, ドキュメント | **保持** |

### 変更理由
- 医用研究のため患者識別情報(ファイル名の患者ID)を公開リモートへ出さない。push は取り消しにくい(キャッシュ・インデックス残存)ため、コミット前の機械的検証を必須とした。
- モデル `.pth` は患者由来かつ大容量(419MB)で git 管理に不向き → 別途配布。

### ハマった点と解決策
- 問題: ジャンクファイル(特殊文字を含むファイル名)が当初の `.gitignore` パターンに一致せずステージされてしまった。
- 解決策: 実際のファイル名に合わせて `.gitignore` パターン(`*Eyelid_HITL_experiment_seg.txt`)を修正し、`git rm --cached` 相当でステージから除外。再度ステージ内容を検証してクリーン(49ファイル＝コード・ドキュメント・研究ノート・安全なログのみ)を確認してからコミット。
- 問題: `gh` CLI 未インストール、自動インストールが UAC 昇格要求で中断 → `gh repo create` での自動作成は不可。
- 解決策(実行・成功): GitHub 側で空 private リポジトリを作成し URL を提供してもらい → `git remote add origin <URL>` / `git branch -M main` / `git push -u origin main`。**GCM によりブラウザ1回サインインで認証(PAT手入力不要)し push 成功**。`gh` CLI 自体は不要だった。
- 補足(未実施・提案): 別マシンでこのリポジトリから動かす場合、除外した `experiment.json` は `scripts/prepare_experiment.py` で(元データがあれば)再生成、モデル `*.pth` は別途コピーが必要。この再現手順を README に1段落追記するかはユーザー回答待ち。
