## Gmail 下書きの「段落内で改行しない」書き方を claude-skills リポジトリに共有(push 済み `8311c75`)

### 概要
- ユーザー指示(2026-10-13): 段落内で改行しない書き方を `https://github.com/ykitaguchi77/claude-skills.git` にも共有する。名乗り(「大阪大学の北口です」)は個人名なので GitHub には入れない。
- この PC には skills リポジトリのローカルコピーがない(`~/.claude/skills` は clone ではない)ため、scratchpad に一時 clone して作業した。
- 新しいスキルは作らず、既存の `gmail-draft-attach/SKILL.md` を更新した。このスキルには「段落内で改行しない」規則がすでにあり、Gmail 下書きを頼んだときに呼ばれるスキルでもあるため。
- 変更内容: 旧規則は「各段落をテキストの 1 行で書く」だった。テキスト形式だと Gmail が長い行を自動で折り返すため、これでは改行を防げない。新しい規則は次のとおり。
  - 本文は HTML で書き、1 段落を 1 つの `<p>` にして段落内で改行しない。
  - `<br>` は見出し・リンク・ID/PASS の行・箇条書き・表の行だけに使う。
  - 下書きを作成・更新したら開き直し、宛先・cc・差し込んだリンクが残っているか確認する。
- 名乗りはこの PC のローカルメモリ(`gmail-draft-style.md`)だけに残し、リポジトリには入れていない。
- 検証: `bin/lint-skills.sh` は初回、Windows の文字コード(cp932)エラーで検査前に落ちた。`PYTHONUTF8=1` で再実行すると、ブロッキングエラーなしで通った。警告は 1 件で、今回の変更とは無関係の既存のもの(drive-upload ↔ paper-fetch)。
- `git pull --rebase` の後に commit `8311c75` を作り、push した。Mac 側には `~/.claude/skills/bin/sync-skills.sh`(または `git pull`)で反映する。
