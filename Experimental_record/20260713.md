## ポート8000の bind エラー(WinError 10048)を解消(運用対応・コード変更なし)

### 概要
- ユーザーが手元の PowerShell で `python -m uvicorn main:app --port 8000` を起動しようとしたところ、
  **`[Errno 10048] error while attempting to bind on address ('127.0.0.1', 8000)`**(=ポート使用中)で
  application startup 直後に shutdown する状態になっていた。
- 原因は、**前セッションで私(Claude)が検証用に起動したままにしていたバックグラウンドの uvicorn**
  (タスク ID `bwulo75b4`)がポート8000を掴み続けていたこと。ユーザー自身の起動がその競合で bind に失敗していた。

### 対応
- 残存していた検証用バックグラウンドサーバー(uvicorn on :8000)を停止:
  `Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like '*uvicorn*8000*' } | Stop-Process -Force`。
- 停止後にポート開放を確認(`curl http://localhost:8000/api/config` が無応答=空き、`:8000` を Listen するプロセスなし)。
- ユーザーへは、手元の PowerShell で起動コマンドを再実行すれば正常に立ち上がること、
  外部公開まで一気にやる場合は `scripts/webapp/run_server.bat` / `run_server.ps1` を使うこと、
  今後 10048 が出たら `Get-NetTCPConnection -LocalPort 8000 -State Listen` で掴んでいる PID を特定して
  `Stop-Process` できることを案内した。

### 再発防止(自分への申し送り)
- **検証用に立てたバックグラウンドサーバーは、検証完了後に必ず停止してポートを塞がない**。
  医用画像を扱うサーバーでもあり、放置は公開リスク・ポート競合の両面で望ましくない。

## Cloudflare Tunnel の固定URL化について確認応答(確認のみ・コード変更なし)

### 概要
- ユーザー質問「Cloudflare の tunnel は課金すれば固定URLにできるんでしたっけ?」に回答。
- 要点は **「Cloudflare への課金は基本的に不要」**。固定URLは無料プランで実現でき、条件は **自分のドメインを持っていること** のみ。

### 回答内容
- 現状の `run_server.ps1` が使うのは **quick tunnel**(`cloudflared tunnel --url ...`)で、
  `xxxx.trycloudflare.com` の**ランダムURL・再起動ごとに変わる**方式。本番向けではない。
- 固定URLには **named tunnel(名前付きトンネル)** を使う。**Cloudflare 無料プランで利用可能**でトンネル機能自体に課金は不要。
- 必要なもの: Cloudflare アカウント(無料)+ named tunnel(無料)+ **自分のドメイン**(Cloudflare プランは無料だが**ドメイン取得料は別途** 年 ~1,000〜1,500円程度)。
  → つまり「Cloudflare に課金」ではなく「ドメインを1つ持つか取るか」が条件。
- セットアップ手順(ドメイン前提): `cloudflared tunnel login` → `tunnel create hitl` → `tunnel route dns hitl hitl.example.com` → 設定ファイルで `hitl.example.com → http://localhost:8000` を指定して起動(Windows サービス化で常駐可)。再起動しても `https://hitl.example.com` のまま。
- **医用データ向けの推奨**: named tunnel なら **Cloudflare Access(無料枠50ユーザー)** を重ねられ、共有PWの代わりに**3名のメールアドレスへワンタイムコードでログイン**させられる(現行 Basic 認証より堅牢・併用可)。
- ドメインを買いたくない場合: quick tunnel のまま毎回URL共有 / **Tailscale Funnel** などドメイン不要で固定URLを出せる別サービスも選択肢。

### 申し送り
- ドメインが決まれば named tunnel + Cloudflare Access を `run_server.ps1` へ組み込む形で用意可能(未実装・ユーザー判断待ち)。
