## 1. 研究の問い・仮説

**主問**: セグメンテーション提案モデルが学習したアノテーション枚数 n（= オンライン学習の進み具合）が増えるにつれ、
その提案を初期値とする HITL アノテーションの人の手間はどう減り、どこで頭打ちになるか。品質は人手と同等を保つか。
また、提案の「参照 GT までの修正量」（後ろ向きシミュレーションで事前計算）は実測の手間を予測するか。

- **H1（効率、主要）**: 提案あり条件（n ≥ 1）で、画像 1 枚あたりの active 作業時間は log₂ n に対して減少する。
- **H2（品質非劣性、共主要）**: 構造ごとに、n が十分大きい条件では最終アノテーションの対 GT ASSD が手動（n = 0）
  に対して非劣性（マージン §6）。n = 128 から降順に検定し、非劣性が成り立つ最小の n* を報告する。
- **H3（オートメーションバイアス）**: 提案の対 GT 誤差が最終アノテーションの誤差に持ち越される（同一画像の
  手動アノテーションで画像難易度を調整したうえで、傾き > 0）。
- **H4（主観負荷）**: Paas 努力度は log₂ n に対して低下する。
- **H5（新規性：提案品質が手間を予測する）**: 事前計算した提案の修正量（対 GT ASSD 等）は作業時間を説明し、
  これを入れると log₂ n の効果は消失または大きく減衰する（n の効果は提案品質を介する）。

## 2. デザイン（固定済み・要約）

- **被験者**: 6 名（GT 作成者は除外）、被験者内。`scripts/study_design.py` の割付則は被験者数 A をパラメータとし、
  A ∈ {3, 5, 6} で組める（A=6 が本計画。A を変えた場合は本書 §6 の数値を再計算して改訂する）。
- **条件**: n ∈ {0（手動）, 1, 2, 4, 8, 16, 32, 64, 128}。n ≥ 1 の提案は **固定チェックポイント**（SAM2.1 Hiera-L の
  mask decoder に構造別 LoRA r=8、学習順の先頭から 1 枚ずつ追加・各 1 epoch の逐次学習、lr 1e-3、AdamW 状態保持、
  反転増強）から出す。eyelid / iris / pupil の 3 構造すべてに同じ n を使う。学習順は patient-stratified random を
  **3 seed**（seed 0/1/2）→ 3 × 3 × 8 = 72 チェックポイント。素の SAM（学習なし）条件は置かない
  （モデル側指標 n = 0 として報告）。
- **提案は全 (画像, n, seed) をオフラインで事前計算**し、実験アプリは JSON を参照するだけ（推論待ち時間ゼロ、
  手動・提案で応答時間が同一 → タイミングによる条件推測不能）。
- **画像**: 学習・評価に一切使わない held-out プール（image_id 2500–2999、患者単位で分離）から 60 枚（正面 36 +
  周辺 24、視線は虹彩偏心度 de-baseline 0.20 で自動分類、患者あたり ≤5 枚）+ 練習 5 枚。学習順 3 seed とモデル
  評価セット（200 枚）は研究画像プールの全患者を除外して生成（`prepare_experiment.py` が両方向を assert）。
- **割付**: 条件スロット S = 12（n×8 + 手動×4）、画像 = 12 グループ × 5 枚（各 3 正面 + 2 周辺）。
  被験者 a・グループ g のスロット = slots[(g + 2a) mod 12]。→ 各画像は 6 名が**互いに異なる**スロットで作業し、
  **手動はちょうど 2 名**（研究内 inter-rater）、提案あり 4 種の n。1 名 = **6 セッション × 10 枚** = 60 枚
  （手動 20 + 各 n 5 枚）。各 (被験者, n) の 5 枚は seed を 2/2/1 に割り、n ごと全体で seed 10/10/10。
- **セッション**: 各セッション = 12 スロットのうち 10 スロットから 1 枚ずつ（同じ n は 1 セッションに 1 枚まで、
  手動 3〜4 枚）を**ランダム順**、n・seed・条件は非表示。欠ける 2 スロットは巡回し、各スロットは 6 セッション中
  ちょうど 1 回だけ欠ける（`study_design.session_slots`、被験者ごとに n の並びを回転）。周辺画像は各セッションの
  周辺枚数が最少のセッションへ貪欲配置し、セッションあたり周辺 3〜5 枚（多くは 4）に均す。
  被験者はセッション内・間で戻れない。練習（手動 2 + 提案 3（n = 4/16/64, seed 0）、GT 表示）は解析除外。
- **盲検**: クライアントには n / seed / モデル名 / 条件 / グループ / ファイル名を送らない。手動項目は提案が無いこと
  で判別できる（ベースラインとして意図的）が、n の間は判別不能。事後質問票で「品質差に気づいたか・n を推測
  できたか」を manipulation check として尋ねる。
- 1 名あたり本解析対象 60 画像、総観測 360（手動 120、各 n 30）。

## 3. データソースと前処理

- 入力: `outputs/results/*/summary.csv` を全連結（`scripts/analysis/fit_models.py::load_results`）。必要に応じ
  `records.jsonl` の `events[]` / `heartbeats[]` / `proposal_metrics`。
- 除外: `is_practice == True`、`annotator == "test"`（開発者の機能テスト）。
- やり直し（`attempt ≥ 2`）: 同一 `annotator × session_key × image_id` に複数記録がある場合、**attempt 1** を採用
  （記憶効果を避ける）。attempt 1 がセッション未完の場合は最新の完了試行を採用し報告する。
- 離席疑い（`duration_sec` が同一被験者×条件の中央値の 5 倍超、または `heartbeats[]` に 60 秒超の欠落）は主解析に
  含め、感度解析で除外。
- 派生変数: `log2n = log₂ n`（n ≥ 1）、`gaze_p`（周辺 = 1）、`redraw = shapes_deleted > 0`、
  クラス別 `{k}_vertices_added/moved/deleted`、`{k}_shapes_created/deleted`（提案を捨てて描き直したか）。
  提案品質（事前計算、`{k}_prop_dice/_prop_assd/_prop_hd95/_prop_bf1/_prop_area_diff`）は summary.csv に同梱。

## 5. 統計解析（`scripts/analysis/fit_models.py`）

推定はすべて **被験者と画像の交差変量切片**（statsmodels MixedLM の variance components、REML）。被験者 6 水準は
変量効果として扱える下限付近のため、分散が 0 に退化した場合は被験者を固定効果に切り替える（事前決定）。

### 5.1 記述統計
条件別（手動, n = 1 … 128）に主要・副次の中央値 [IQR]・平均 (SD)、被験者別・視線別の層別表。モデル側曲線
（`outputs/model_eval/summary.csv`: 各チェックポイントの患者分離 200 枚での Dice / ASSD / HD95 / BF@2px、seed 別 +
平均、n = 0 = 未学習参照点）を並記。手動項目（各画像 2 名）の被験者間 ASSD / Dice を研究内 inter-rater として報告。

### 5.2 主解析（H1）: 用量反応
提案あり条件（n ≥ 1）で
```
log(duration_sec) ~ log2n + gaze_p + order_in_session + session_index + C(seed)
                    + (1 | annotator) + (1 | image_id)
```
- `log2n` の係数（倍増あたりの時間比 = exp(β)）と 95% CI、片側検定（β < 0）、α = 0.05 が主結果。
- 飽和: n 別平均（log）に `a + b·exp(−n/τ)` を当てはめ、`a + b·log₂ n` と AIC 比較。減衰が優れる場合は τ と
  漸近値の 10% 以内に入る n₉₀ を報告（cluster bootstrap で CI）。
- 手動 vs 各 n（8 対比、Holm）は副次。同一画像の手動 2 名を含む交差モデルで画像難易度を調整。
- 分布: log-normal を主、Gamma GLMM（log link）を感度解析。

### 5.3 品質非劣性（H2, 共主要）
構造 k ごとに
```
{k}_assd ~ C(condition, ref = manual) + gaze_p + (1 | annotator) + (1 | image_id)
```
- 各 n の（n − 手動）差の片側 95% CI 上限 < δ_k で非劣性。**固定順序**: n = 128 → 64 → … と降順に検定し、最初に
  失敗した n で停止 → 「n ≥ n*_k で非劣性」。多重性は固定順序で制御（構造 3 つは並列に報告、Holm 不要の
  階層とせず各構造で独立に結論）。
- δ_k（px）は研究開始前に開発者（被験者外）の手動 20 枚 vs CVAT GT の構造別 inter-rater ASSD から
  δ_k = 0.5 × inter-rater ASSD として決め §6 に記入（eyelid は既知 2.3 px → δ ≈ 1.15 px と整合確認）。
- Dice（差 −0.01）・HD95（差 +2 px）は補助として同じ枠組みで報告。虹彩・瞳孔は加えて**中心誤差**（px と虹彩半径比）と
  **水平/垂直径誤差**、画像単位の **MRD1/MRD2/PFH 誤差（mm）** を同じ混合モデルで手動と比較し、臨床的許容 ±0.5 mm 内かを
  記述する（検証的検定は ASSD のみ）。
- H1 と H2 は階層（H1 有意 → H2 へ）。「速くて劣らない」は両方成立で主張する。

### 5.4 オートメーションバイアス（H3）
提案あり条件で
```
{k}_assd ~ {k}_prop_assd + gaze_p + manual_assd_same_image + (1 | annotator) + (1 | image_id)
```
`manual_assd_same_image` = 同一画像の手動 2 名の対 GT ASSD 平均（画像難易度の直接調整）。傾き > 0 なら持ち越し。
補助: `redraw` 率 vs log₂ n（ロジスティック混合モデル）。

### 5.5 主観負荷（H4）
`effort ~ log2n + gaze_p + (1 | annotator) + (1 | image_id)`（線形を主、累積リンクを感度解析）。

### 5.6 新規性（H5）: 提案品質が手間を予測する
提案あり条件で 3 モデルを比較: (a) `log(duration) ~ prop_assd_mean + 共変量`、(b) `~ log2n + 共変量`、
(c) `~ prop_assd_mean + log2n + 共変量`。(c) で log2n の係数が (b) に比べ減衰・非有意になれば「n の効果は
提案品質を介する」と解釈。`prop_assd_mean` の係数（1 px あたりの時間比）と尤度を報告。
モデル側曲線（評価 200 枚）と被験者側曲線（手間）を同じ横軸 n で並べ、シミュレーションが手間を予測する図を作る。

### 5.7 クラス別解析（探索的）
`{k}_time_sec`（既定選択クラスの初期観察時間を補正）・`{k}_clicks`・`{k}_vertices_*` で 5.2 を繰り返し、
ポリゴン（眼瞼）と楕円（虹彩・瞳孔）で用量反応の形が異なるかを記述。

### 5.8 品質ゲート（記述）
構造ごとに `{k}_assd > 2 × inter-rater ASSD` を不合格とし、不合格率を n 別に報告（主要評価には使わない：
不合格を除外すると生存時間に選択バイアスが入るため）。

### 5.9 多重性
- 検証的検定: H1（1 本）→ H2（構造ごと固定順序）。副次・探索的は 95% CI 中心、名目 p。事前対比のみ Holm。

### 5.10 欠測・逸脱
- 3 クラス必須ガード・負荷回答必須のため欠測は生じない。空提案（低 n で起こる）は「提案あり条件の一部」として
  そのまま解析（用量の一部）。空提案率を n 別に報告。
- 計画からの逸脱は Supplement に列挙。

### 5.11 検出力（`scripts/analysis/power_sim.py`）
本デザイン（6 名・360 観測）で、手動→n=128 の時間比 0.7（log₂ n 1 単位あたり −5%）・log 残差 SD 0.5・被験者/画像
SD 0.3 の条件でシミュレーション（300 反復）した H1 の検出力、および H2（真の差 0〜0.5 px、δ = 1 px、残差 SD 1 px）の
検出力を `outputs/analysis/power_sim.csv` に記録し、事前登録に添付する（結果は §6 表）。
- **パイロット実測（開発者 1 名、test Session 1〜3 = 30 枚、2026-09-20）**: 作業時間の残差 SD（log、n・視線・
  セッション除去後）0.35、n の効果 −12%/倍増（n=1→128 で比 0.43）、手動 vs n=128 の中央値比 0.50。
  ASSD 残差 SD: 眼瞼 0.76 px / 虹彩 3.1 px / 瞳孔 1.8 px。この値で再計算した検出力: H1 は効果を比 0.7 まで
  落としても 1.00（SD 0.5 でも 0.98）、比 0.85 で 0.81。H2 は眼瞼（δ 0.8 px、SD 0.8）真差 0.3 px で 0.86、
  虹彩（δ 2.3 px、SD 3.1）真差 0.5 px で 0.85・1.0 px で 0.65 → 虹彩は非劣性の検出力に余裕が少ないため、
  δ_iris の決め方（0.5 × inter-rater か inter-rater そのものか）を登録前に確定する。
  被験者間分散は未観測（シミュレーションでは被験者 SD 0.3 を仮定）。
  同パイロットの手動 10 枚（`rescore_records.py` で再採点）: 虹彩中心誤差 4.6 px（SD 2.7）、水平径 +3.7 px / 垂直径 −0.2 px
  （開発者は CVAT よりやや大きく描く系統差）、瞳孔中心誤差 2.4 px、|MRD1 誤差| 0.14 mm、|PFH 誤差| 0.07 mm。
