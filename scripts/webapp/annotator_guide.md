# アノテーション作業ガイド（アノテータ用）

まぶた・虹彩・瞳孔のセグメンテーション・アノテーション実験へのご協力ありがとうございます。
ブラウザだけで作業できます（インストール不要）。所要は1セッション10枚 × 全10セッション程度です。

---

## 1. ログイン

1. 配布された **URL**（`https://xxxxx.trycloudflare.com`）をブラウザで開く
   （Chrome / Edge 推奨。いつも**同じPC・同じブラウザ**を使ってください）
2. ユーザ名 `annotator` と配布された**パスワード**を入力
3. **アノテータ番号**（あなたに割り当てられた `1` / `2` / `3`）を選択
   - 「動作テスト用」は選ばないでください（本番データに含まれません）

---

## 2. 作業の流れ

セッションは上から順に開きます（前を終えると次が開く）:

| 順 | セッション | 内容 |
|---|---|---|
| 1 | 練習1 Scratch | ゼロから描く練習。提出後に**正解(GT)が点線**＋スコアで表示されます |
| 2 | 練習2 修正 | AIの予測を直す練習。同じく提出後に正解を表示 |
| 3 | Scratch | 本番・ゼロから作成（10枚） |
| 4〜11 | Session 1〜8 | 本番・AI予測を修正（各10枚） |

- **練習だけ**、提出後に正解と一致度(Dice)が出ます（慣れるため）。**本番では正解は出ません。**
- 本番セッションでは、**どのAIモデルの予測かは表示されません**（盲検）。予測の良し悪しを気にせず、
  「正しいと思う輪郭」に淡々と修正してください。
- 各セッションの間は休憩できます。**PCを閉じず**、同じブラウザで再開してください。

---

## 3. 描くもの（3クラス）

右サイドバーの**クラスタブをクリックして対象を選んでから**編集します。

| クラス | 形 | 描き方 |
|---|---|---|
| **まぶた (eyelid)** | ポリゴン | 開いている眼瞼裂の輪郭。**涙丘（カルンクル）も含めて一体**で囲む（境界線は引かない） |
| **虹彩 (iris)** | 楕円 | 円/楕円で囲む。**周辺視（横目）では楕円を傾ける** |
| **瞳孔 (pupil)** | 楕円 | 同上。周辺視では傾ける |

- 各クラスは基本1つ。**クラスタブを押すと、そのクラスの図形が選択状態**になり、
  他クラスと重なっていても動かせます。
- 周辺視の画像（各セッションに数枚）は楕円を傾ける必要があります。練習で慣れてください。

---

## 4. 操作（ツールバー左）

| ボタン | ツール | 操作 |
|---|---|---|
| ▢ | 選択 (V) | 図形/頂点をクリックで選択 → ドラッグで移動、Backspace/Escで頂点削除。**何もない所をドラッグで画像を移動**。ポリゴン選択中に **Shift+クリックで点を追加**（ダブルクリックで確定） |
| ⬡ | ポリゴン (P) | クリックで頂点追加 → 最初の点付近クリックかダブルクリックで閉じる |
| ◯ | 楕円 (E) | ドラッグで楕円作成 → 選択ツールで回転・リサイズ |
| ✋ | 移動 (space) | ドラッグで画像移動、ホイールで拡大縮小 |
| ↶ / ↷ | 元に戻す/やり直し | Ctrl+Z / Ctrl+Y |
| 🗑 | 削除 | 選択図形を削除 (Del) |
| ⤢ | 全体表示 (F) | 画像全体を表示 |
| ⛶ | 最大化 | ウィンドウいっぱいに表示 |
| 🎨 | 塗り表示 | 塗りつぶし表示のON/OFF |

- 右サイドバー下部の **明るさ・コントラスト**スライダーで見やすく調整できます（保存には影響しません）。
- スペースキーでも点を追加できます。

---

## 5. 提出と中断

- **提出して次へ →**（右上・緑）: 現在の画像を保存して次へ。
- **中断**（右上・赤）: 所要などで続けられないときの**フォールバック**。
  押すと**そのセッションの記録は破棄**され、同じセッションを最初からやり直せます。
  通常は使わないでください。

> 作業時間は効率の指標として記録されます（AIの推論待ち時間は除外されます）。
> 焦らず、ふだん通りの精度で作業してください。

---

## 6. 困ったとき

| 症状 | 対処 |
|---|---|
| URLが開けない | 管理者にPCが起動中か確認を依頼 |
| ログインを何度も聞かれる | ユーザ名 `annotator` とパスワードを再確認 |
| 予測がなかなか出ない | 「推論中…」表示が消えるまで待つ（自動で入力可能になります） |
| 操作に迷った | 画面下のヒント表示を参照、または管理者へ連絡 |

ご協力に感謝します。
