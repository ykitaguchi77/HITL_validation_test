# アノテーション作業ガイド（アノテータ用）

まぶた・虹彩・瞳孔のセグメンテーション・アノテーション実験へのご協力ありがとうございます。
ブラウザだけで作業できます（インストール不要）。練習2 + 本番 Session 1〜6 の**全8セッション**、
本番は1セッション10枚（合計60枚、目安 1.5〜2 時間）です。

---

## 1. ログイン

1. 研究者から届いた**あなた専用のリンク**（`https://xxxxx.trycloudflare.com/?t=…`）をブラウザで開く
   （Chrome / Edge 推奨）。リンクは他の人と共有しないでください
2. ユーザ名 `annotator` と配布された**パスワード**を入力
3. 画面上部に **「アノテータ: （あなたの名前）」** と表示されることを確認
   - 自分の名前でなければ作業せずにページを閉じ、研究者に連絡してください
   - 「このリンクは無効です」と出たら、届いたリンクをそのまま（末尾まで）開き直してください
   - 進捗はサーバに記録されるので、PC・ブラウザが変わっても続きから再開できます

---

## 2. 作業の流れ

セッションは上から順に開きます（前を終えると次が開く）:

| 順 | セッション | 内容 |
|---|---|---|
| 1 | 練習1 ゼロから描く | 提案なしで描く練習（2枚）。**練習のみ、完成後に模範解答が点線**＋スコアで表示されます。微妙な部分のニュアンスを模範解答で確認し、本番でも模範解答と同じようなアノテーションができるように練習してください |
| 2 | 練習2 予測を直す | AIの提案を直す練習（3枚）。同じく提出後に模範解答を表示。**提案が大体合っていても、ピクセル単位で模範解答と同じになるまで直す**のが本番のルールです |
| 3〜8 | Session 1〜6 | 本番（各10枚）。**AIの提案がある画像と、無い画像（ゼロから描く）が混ざって**出ます |

- **練習だけ**、提出後に正解と一致度(Dice)が出ます（慣れるため）。**本番では正解は出ません。**
- 本番では画像を開いたとき、**提案が表示されていればそれを修正**、**何も表示されなければゼロから描いて**ください。
  提案の品質は画像によってかなり違います（ほとんど合っているものから、大きくずれている・一部しか無いものまで）。
  **どの段階のAIの提案かは表示されません**（盲検）。提案の良し悪しを気にせず、「正しいと思う輪郭」に淡々と
  仕上げてください。
- **目標は、練習で見た模範解答と同じアノテーション**です。提案が大体合っていても、ピクセル単位で模範解答を
  目指してください。いつも通りのペースで作業してください。
- **予測の直し方は自由です。** 頂点を動かして直しても、図形を削除（🗑 / Del）してゼロから描き直しても構いません。
  画像ごとに「自分が一番早く正確に仕上げられる」と思う方法を選んでください（どちらが正しいということはありません）。
- 各セッションの間は休憩できます。再開するときも**自分専用のリンク**から開いてください。

---

## 3. 描くもの（3クラス）

右サイドバーの**クラスタブをクリックして対象を選んでから**編集します。

| クラス | 形 | 描き方 |
|---|---|---|
| **まぶた (eyelid)** | ポリゴン | 開いている眼瞼裂の輪郭。**涙丘（カルンクル）も含めて一体**で囲む（境界線は引かない） |
| **虹彩 (iris)** | 楕円 | 円/楕円で囲む。**周辺視（横目）では楕円を傾ける** |
| **瞳孔 (pupil)** | 楕円 | 同上。周辺視では傾ける |

- 各クラスは基本1つ。**クラスタブを押すと、そのクラスの図形が選択状態**になり、
  他クラスと重なっていても動かせます。
- 周辺視の画像（各セッションに数枚）は楕円を傾ける必要があります。練習で慣れてください。

---

## 4. 操作（ツールバー左）

| ボタン | ツール | 操作 |
|---|---|---|
| ▢ | 選択 (V) | 頂点をドラッグで移動、辺の中点をドラッグで点追加、頂点クリック→Backspaceで削除。**何もない所をドラッグで画像を移動**。ポリゴン選択中に **Shift+クリックで点を追加**（ダブルクリックで確定）／**Ctrl+ドラッグで複数の頂点を四角く囲んで、まとめて移動・Delete でまとめて削除**（Escで解除） |
| ⬡ | ポリゴン (P) | クリックで頂点追加 → 最初の点付近クリックかダブルクリックで閉じる |
| ◯ | 楕円 (E) | ドラッグで楕円作成 → 選択ツールで回転・リサイズ |
| ✋ | 移動 (space) | ドラッグで画像移動、ホイールで拡大縮小 |
| ↶ / ↷ | 元に戻す/やり直し | Ctrl+Z / Ctrl+Y |
| 🗑 | 削除 | 選択図形を削除 (Del) |
| ⤢ | 全体表示 (F) | 画像全体を表示 |
| ⛶ | 最大化 | ウィンドウいっぱいに表示 |
| 🎨 | 塗り表示 | 塗りつぶし表示のON/OFF |
| ? | チュートリアル | 操作説明を開く（初回セッション開始時に自動表示。開いている間は計測が止まります） |

- 右サイドバーの **「操作（今できること）」** に、いまの状態（ツール・選択中の図形/頂点）で使える操作がつねに表示されます。

- 右サイドバー下部の **明るさ・コントラスト**スライダーで見やすく調整できます（保存には影響しません）。
- スペースキーでも点を追加できます。

---

## 5. 提出と中断

- **提出して次へ →**（右上・緑）を押すと**確認画面**が出ます。輪郭を最終確認して次のいずれかを選びます:
  - **確認OK・次へ →**: この内容で確定 → 続けて**負担度を1〜9**（1=非常に少ない〜9=非常に大きい）で回答 → 保存して次の画像へ
  - **修正する**: 提出を取りやめて編集に戻ります（計測時間もそのまま続きます）
  - **中断**: 下記の中断と同じ（そのセッションの記録を破棄してやり直し）
- **中断**（右上・赤）: 所要などで続けられないときの**フォールバック**。
  押すと**そのセッションの記録は破棄**され、同じセッションを最初からやり直せます。
  通常は使わないでください。

> 作業時間は記録されますが画面には表示されません（画像の読み込み待ち時間は除外されます）。いつも通りのペースで作業してください。
>
> **別のウィンドウ・アプリに切り替えると自動的に一時停止**します（その間は時間にカウントされません）。
> このウィンドウに戻ると自動で再開します。短い離席はそのままで大丈夫です。

---

## 6. 困ったとき

| 症状 | 対処 |
|---|---|
| URLが開けない | 管理者にPCが起動中か確認を依頼 |
| ログインを何度も聞かれる | ユーザ名 `annotator` とパスワードを再確認 |
| 画像がなかなか出ない | 「読み込み中…」表示が消えるまで待つ（自動で入力可能になります） |
| 操作に迷った | 画面下のヒント表示を参照、または管理者へ連絡 |

ご協力に感謝します。
